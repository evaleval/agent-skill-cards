# Skill Card schema v1.2 with structure and examples

## Structure and example columns, v1.2

Added 28 October 2026. The seven section files in this folder repeat the v1.2 tables with two more columns. Structure says the form a value takes. Example shows that form filled for the pdf skill, anthropics/skills at dbd4588f, as read on 22 October 2026. Where the pdf skill has no value, the example gives the empty word and then an imaginary filled value, marked as imaginary.

### Value kinds

A value is a word from a fixed list, a number, a date written as YYYY-MM-DD, a link, a short phrase, or a sentence where the structure says so. A field that holds several things is a list with one item per thing, and every item has the same slots in the same order. An item ends with its source, one of author, registry, check with the check's id, model, pipeline or review. A field or slot that holds nothing carries one of the four words none, not declared, not examined or unknown, never a blank.

### How the examples are written

Items stand one per line in the order of the slots the structure names, separated by a middle dot. Commands and file contents are quoted as written. The value of a secret is never written.
