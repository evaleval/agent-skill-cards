# Skill Card: lark-doc larksuite/cli at ac22a60a

## 1. What it does

| Field | Value |
|---|---|
| **Name** | lark-doc |
| **Description** | Instructions for the lark-cli docs and mindnotes commands, for working with Feishu and Lark cloud documents of type Docx and Wiki. It reads whole documents or parts by outline, section, range or keyword, creates documents from XML or Markdown through an authoring workflow, edits them block by block, lists or reverts history versions, handles images, attachments, covers and whiteboards, and edits existing mindnotes. Results come back as JSON from lark-cli, as changed online documents or as files saved locally. Use it when the user gives a document URL or token, including doubao.com /docx/ and /wiki/ links. |
| **Tasks** | • read and summarise Docx and Wiki documents, whole or in part<br>• create documents from XML or Markdown through a step-by-step authoring workflow<br>• edit documents by text replacement or block insert, replace, move and delete<br>• list and revert document history versions<br>• insert, preview and download images, attachments, covers and whiteboard thumbnails<br>• create whiteboards from Mermaid or SVG inside a document<br>• read nodes of existing mindnotes and create or update nodes |
| **Outputs** | • document content with reference_map, visible unresolved comments and tips (information), JSON from lark-cli, content in XML, Markdown or im-markdown, to the agent's context<br>• new or changed online documents, with document_id, url, revision_id and new_blocks (action), Feishu cloud document, to the user's Feishu or Lark space<br>• reverted history versions, document covers and mindnote nodes (action), change to an online document or mindnote, to the user's Feishu or Lark space<br>• downloaded or previewed media, covers, whiteboard thumbnails and previews (information), image or file, to a local path given with --output, for instance ./asset.png or ./preview.png<br>• authoring workspace with .presentation-decision.json and the draft XML (information), local files, to draft_&lt;8位十六进制字符>_folder/draft.xml under the returned data.cwd, kept after delivery<br>• draft profile with word count, block count and diagnostics (information), JSON from docs +script parse, to the agent's context<br>• a direct link to a block (information), URL text, to a message to the user |
| **Sample output** | `"url": "https://xxx.feishu.cn/docx/docx_token"` |
| **Inputs** | • a document URL or token, a /docx/ or /wiki/ URL, a token or a #share selection link, required for every document task, example `lark-cli docs +fetch --doc Z1Fj...tnAc --scope outline --max-depth 3`<br>• document content, XML or Markdown, inline, from an @ file or from stdin, conditional for creating or updating a document, example `lark-cli docs +create --doc-format markdown --content "@./draft.md"`<br>• a Presentation Decision, a JSON object with audience, reader_task, presentation_mode and visual_plan, conditional for authoring a document from scratch, example `lark-cli docs +script --command init-draft --presentation-decision '<上方完整 JSON>' --format json`<br>• a local image or file, a clipboard image or an HTTPS image URL, a path, the --from-clipboard flag or a URL, conditional for inserting media or updating a cover, example `lark-cli docs +media-insert --doc doxcnXXX --file ./image.png`<br>• a resource token and an output path, file_token or whiteboard_id and a local path, conditional for previewing or downloading media and whiteboard thumbnails, example `lark-cli docs +media-download --token "Z1Fjxxxxxxxx" --output ./asset`<br>• a target version, a history_version_id, a revision_id or a point in time, conditional for reverting a document, example `lark-cli docs +history-revert --doc "<docx_url_or_token>" --history-version-id 42`<br>• a mindnote token and a node request body, a Mindnote token and JSON with nodes, conditional for reading or editing an existing mindnote, example `lark-cli mindnotes nodes list --mindnote-id "<mindnote_token>"`<br>• the identity to act as, the --as flag, user or bot, optional for every command, --as user recommended for documents, example `--as user` |
| **When an input is missing** | • the clipboard holds no image: the user is told and asked for a local file path, then the same insert command is retried with --file<br>• several history versions share the given revision_id and cannot be told apart: the user is asked to confirm which one to revert to<br>• no block_id is available for a requested direct link: no link is guessed<br>• the user is not authenticated or a token, identity or scope error occurs: lark-shared is read, the problem fixed and the command retried<br>• the target version cannot be read: stop and report<br>• a cover download on a document without a cover: the command fails with document has no cover and creates no file |
| **Exclusions** | • not for Drive file-level operations such as finding, importing, exporting, uploading, downloading or permissions, which go to lark-drive<br>• not for standalone comment operations, which go to lark-drive<br>• not for data inside sheets or Base<br>• not for /page/&lt;token> links, which are 妙搭 apps and not Feishu documents<br>• not for only viewing or downloading existing whiteboards, which go to lark-whiteboard |
