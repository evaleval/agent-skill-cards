## 1. What it does

| Field | Value |
|---|---|
| **Name** | shadcn |
| **Description** | Instructions, rule files and one Node script for working with shadcn/ui projects through the shadcn CLI. At load the project context is injected by running npx shadcn@latest info --json, and the agent then searches registries, adds, updates and composes components, applies presets and builds registries, following rules on styling, forms, composition, icons and chat UI. A DESIGN.md workflow scaffolds a new app, maps a brand spec onto the theme and builds a design system page, checked with showcase-coverage.mjs. Use it in any project with a components.json file or when working with shadcn/ui, registries or presets. |
| **Tasks** | • search registries and add or update components with the CLI<br>• compose UI from existing components following the critical rules<br>• build chat and assistant UIs from the chat primitives<br>• initialize projects and apply or switch presets<br>• author and build custom registries<br>• turn a DESIGN.md or brand spec into a themed app and design system page |
| **Author's description** | "Manages shadcn components and projects — adding, searching, fixing, debugging, styling, and composing UI, including chat interfaces. Provides project context, component docs, and usage examples. Applies when working with shadcn/ui, component registries, presets, --preset codes, or any project with a components.json file. Also triggers for "shadcn init", "create an app with --preset", "switch to --preset", and for building a design system or applying a DESIGN.md or brand spec to shadcn/ui." |
| **Outputs** | • component, block and hook source files added or updated in the project (action), TSX and TS files, to the resolvedPaths of components.json, such as the ui directory<br>• React code written by the agent that composes the components (information), TSX files, to files in the user's project<br>• theme changes, CSS variables, radius, shadows, fonts and type utilities (action), CSS edits, to the tailwindCssFile, typically globals.css<br>• a new app scaffolded from a template and preset, with a design system page (action), project folder, to a new folder named after the app, sections in src/showcase or app/design-system<br>• built registry item JSON files (information), JSON files, to ./public/r by default<br>• project info, documentation URLs, search results, dry-run diffs and coverage results (information), terminal text or JSON, to the agent's context<br>• a report after a design system build with app path, dev URL, mappings, low contrast pairs and deviations (information), message to the user, to the conversation |
