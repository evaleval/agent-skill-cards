# Skill Card: neon-postgres neondatabase/agent-skills at 392174f4

## 1. What it does

| Field | Value |
|---|---|
| **Name** | neon-postgres |
| **Description** | Instructions and six reference documents for working with Lakebase Postgres on Neon, with no bundled scripts. They cover choosing pooled or direct connections and drivers, branching, migrations, computes, autoscaling, scale to zero, instant restore, read replicas and Neon-specific diagnostics through the neon CLI or the Neon MCP server. The references add branch workflows, a four-step egress optimization procedure and Lakebase Search setup for vector, full-text and hybrid search, with SQL and TypeScript examples. Use it when the work is an existing DATABASE_URL, SQL, schema, inspection or search on Neon. |
| **Tasks** | • pick pooled or direct connections and a driver<br>• create normal or schema-only branches and reset a branch from its parent<br>• diagnose performance with neon inspect db checks<br>• manage computes, autoscaling and scale to zero<br>• find and fix query patterns that cause high egress<br>• set up vector, full-text and hybrid search with Lakebase Search<br>• covers the Neon access path to Lakebase Postgres, not the Databricks one |
| **Outputs** | • a new Neon branch, normal or schema-only, with its connection string (action), Neon branch, to the user's Neon project<br>• the connection string stored as DATABASE_URL (information), a key in an env file, to .env in the workspace<br>• a recommended branch type, connection type or fix, with the commands to run (recommendation), message to the user, to the conversation<br>• diagnostic results from inspect checks and EXPLAIN plans (information), terminal text or MCP tool result, to the agent's context<br>• changed computes, extensions, schema migrations, search indexes and reset branches (action), changes in the Neon project and database, to the user's Neon project<br>• application code with egress fixes, migration files, schema.ts, drizzle.config.ts and neon.ts (information), source files, to the workspace |
| **Sample output** | `` Do you want me to update your `.env` `DATABASE_URL` to this new branch connection string? `` |
