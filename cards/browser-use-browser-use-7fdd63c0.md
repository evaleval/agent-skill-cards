## 1. What it does

| Field | Value |
|---|---|
| **Name** | browser-use |
| **Description** | One SKILL.md for direct browser control via CDP through the browser-use CLI, which runs Python helpers such as new_tab, page_info, click_at_xy, js and cdp from heredocs. It drives the user's local Chrome or Chromium, or managed Chrome instances in Browser Use cloud, and can record traces of browser work. Results are printed page information and extracted content, actions on web pages and optional recordings. Use it when a task needs interaction, the user's logged-in session, JS rendering or a bot-protected page, and not for a basic fetch of public information. |
| **Tasks** | • navigate, click and type on web pages<br>• scrape and extract content through the accessibility tree or js<br>• take screenshots and test sites and apps<br>• run isolated cloud browsers for parallel tasks or bot-sensitive sites<br>• record browser work as traces and videos<br>• diagnose connection problems with browser-use --doctor |
| **Author's description** | "Direct browser control via CDP for web interaction: automation, scraping, testing, screenshots, and site/app work. Also covers hosted cloud browsers for AI agents: the browser-use Python library (Browser()), Playwright, Puppeteer or any CDP client." |
| **Outputs** | • page information and extracted page content (information), printed text, to the terminal and the agent's context<br>• clicks, typing and navigation on web pages, as the user when Chrome is signed in (action), CDP input events in the browser, to the websites the browser visits<br>• a cloud browser started with start_remote_daemon (action), a managed Chrome instance with a live-view URL, to Browser Use cloud<br>• recordings of browser work when recording is enabled (information), local background traces, to the directory start_recording returns<br>• a feedback report on a failure of browser-use itself (action), text sent with browser-use feedback, to the Browser Use team |
| **Sample output** | `ready` |
| **Inputs** | • Python helper code to run in the browser context, a heredoc passed to browser-use, required for every task, example `print(page_info())`<br>• the address of the page to open, a URL, conditional for the first navigation of a task, example `new_tab("https://example.com")`<br>• a daemon name, the BU_NAME variable or an argument to start_remote_daemon, conditional for cloud browsers and named daemons, example `BU_NAME=r7k2 browser-use mac-approve`<br>• a Browser Use API key, an environment variable piped to the CLI, conditional for cloud browsers, example `printf '%s' "$BROWSER_USE_API_KEY" \| browser-use auth login --api-key-stdin`<br>• a CDP endpoint of a given browser, BU_CDP_URL as an HTTP DevTools endpoint or BU_CDP_WS, optional for connecting to a browser other than local Chrome, example not declared<br>• a recording name and title, arguments to start_recording, conditional for recording a task, example `start_recording(name, title=...)` |
