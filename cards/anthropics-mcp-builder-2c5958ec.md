## 1. What it does

| Field | Value |
|---|---|
| **Name** | mcp-builder |
| **Description** | A guide in four phases for creating MCP servers that let LLMs use external services through well-designed tools, with reference guides for TypeScript SDK v2, TypeScript SDK v1, Python FastMCP and MCP best practices. It covers research and planning, implementation of tools with input schemas, pagination and actionable errors, then build and test with npm run build, py_compile and the MCP Inspector. It ends with ten evaluation questions in an XML file and a Python harness that runs them against the server with Claude and writes a report. Use it when building MCP servers to integrate external APIs or services in Python or Node/TypeScript. |
| **Tasks** | • research the MCP specification, SDK docs and the target service's API<br>• set up a TypeScript or Python MCP server project<br>• implement tools with schemas, annotations, pagination and actionable errors<br>• build and test the server with npm run build, py_compile and the MCP Inspector<br>• migrate a TypeScript SDK v1 project to v2 with the codemod<br>• write 10 read-only evaluation questions in an XML file<br>• run the evaluation harness over stdio, sse or http and read the report |
| **Author's description** | "Guide for creating high-quality MCP (Model Context Protocol) servers that enable LLMs to interact with external services through well-designed tools. Use when building MCP servers to integrate external APIs or services, whether in Python (FastMCP) or Node/TypeScript (MCP SDK)." |
