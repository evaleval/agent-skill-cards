# Skill Card: skill-creator anthropics/skills at 2c5958ec

## 1. What it does

| Field | Value |
|---|---|
| **Name** | skill-creator |
| **Description** | Instructions, three subagent prompts, a JSON schema reference and Python scripts for creating agent skills and improving them in a loop. The workflow captures what the skill should do, drafts a SKILL.md, runs test prompts with and without the skill in subagents, grades and aggregates the runs into a benchmark, and shows outputs and benchmark in a browser viewer where the user leaves feedback. A separate loop tests the description against realistic trigger queries through claude -p and proposes better descriptions, and a packager zips the finished skill into a .skill file. Use it to create a skill from scratch, edit or optimize an existing skill, run evals or improve triggering. |
| **Tasks** | • capture intent and draft a new SKILL.md<br>• run test prompts with and without the skill in subagents<br>• grade runs and aggregate a benchmark with mean and stddev<br>• review outputs and leave feedback in a browser eval viewer<br>• compare two skill versions blind<br>• optimize the description for triggering accuracy<br>• package a skill as a .skill file |
| **Author's description** | "Create new skills, modify and improve existing skills, and measure skill performance. Use when users want to create a skill from scratch, edit, or optimize an existing skill, run evals to test a skill, benchmark skill performance with variance analysis, or optimize a skill's description for better triggering accuracy." |
| **Outputs** | • a new or edited skill folder with SKILL.md and bundled resources (information), Markdown and bundled files, to the skill directory<br>• per-run test results, eval_metadata.json, timing.json, grading.json and the outputs of each run (information), JSON files and output files, to &lt;skill-name>-workspace/iteration-N/ next to the skill directory<br>• benchmark with pass rate, time and tokens per configuration and the delta (information), benchmark.json and benchmark.md, to the iteration directory<br>• eval viewer with an Outputs tab and a Benchmark tab (information), HTML page served on a local server or written as a static file, to http://localhost:3117 or the --static path<br>• improvement suggestions for evals and for a losing skill version (recommendation), JSON file, to grading.json, comparison.json and analysis.json<br>• an optimized description with train and test scores and an HTML report (recommendation), JSON on the terminal and an HTML report, to the terminal, the system temp directory or the --results-dir folder<br>• a packaged skill (information), .skill zip file, to the current directory or the output directory given |
| **Sample output** | `Skill is valid!` |
| **Inputs** | • what the skill should do, when it should trigger and its output format, answers in natural language or a workflow in the conversation, required for creating a skill, example `I want to make a skill for X`<br>• an existing skill folder, a path to a directory with SKILL.md, conditional for improving, evaluating or packaging an existing skill, example `python -m scripts.package_skill <path/to/skill-folder>`<br>• test prompts, an evals/evals.json file with id, prompt, expected_output and files per eval, conditional for running test cases, example `{"id": 1, "prompt": "User's task prompt", "expected_output": "Description of expected result", "files": []}`<br>• a trigger eval set, a JSON list of query and should_trigger, conditional for description optimization, example `{"query": "the user prompt", "should_trigger": true}`<br>• a model id, a --model argument, conditional for description optimization with run_loop.py, example `--model <model-id-powering-this-session>`<br>• an iteration directory of the workspace, a positional path argument, conditional for aggregating a benchmark and launching the viewer, example `python -m scripts.aggregate_benchmark <workspace>/iteration-N --skill-name <name>`<br>• the user's feedback on each run, text in the viewer, saved as feedback.json, optional for reviewing results, example `{"run_id": "eval-0-with_skill", "feedback": "the chart is missing axis labels", "timestamp": "..."}` |
| **When an input is missing** | • the conversation already contains the workflow to capture: answers are taken from the conversation history, the user fills the gaps and confirms<br>• the user does not want to run evaluations: the evals are skipped and the skill is iterated by hand with the user<br>• no SKILL.md at the skill path: run_eval.py, run_loop.py and improve_description.py print Error: No SKILL.md found and exit<br>• package_skill.py is called without a path: it prints its usage line and exits<br>• a run directory has no grading.json: aggregate_benchmark.py prints a warning and skips the run<br>• the workspace holds no runs: generate_review.py prints No runs found and exits<br>• a run gets empty feedback: empty feedback is read as the user finding the output fine |
