# Skill Card: hyperframes-cli heygen-com/hyperframes at 84799bdc

## 1. What it does

| Field | Value |
|---|---|
| **Name** | hyperframes-cli |
| **Description** | Instructions and twelve reference documents for driving the HyperFrames CLI, run as npx hyperframes, on HTML video compositions. It scaffolds projects from a blank, an example or a captured website, lints and checks compositions, takes snapshots, edits the timeline and keeps a project history. It previews in Studio and renders MP4, WebM, MOV, GIF, PNG sequences or HLS locally, in Docker, on HeyGen's cloud, on AWS Lambda or on Google Cloud Run, and shares the result. Use it when working on a HyperFrames project from the command line, reading JSON results and recovering from failed commands. |
| **Tasks** | • scaffold a project with init or capture a website as a project<br>• lint and check compositions, then read snapshot PNGs<br>• edit the timeline with move, trim, split, set, duplicate, delete and undo<br>• preview in Studio and render video locally or in Docker<br>• render on HeyGen cloud, AWS Lambda or Google Cloud Run<br>• share or publish a project and send feedback reports<br>• diagnose the environment with doctor and browser |
| **Outputs** | • a scaffolded project with HTML compositions, copied media and transcripts (information), project folder, to a directory the agent names, for instance my-video<br>• lint and check findings with selectors, sample times and suggested colours (information), terminal text or JSON, to the terminal, with check reports saved under .hyperframes/artifacts/checks/<br>• snapshot frames, review sheets, comparison sheets and finding crops (information), PNG and JPG files, to .hyperframes/artifacts/snapshots/&lt;id>/ or the --output or --out path<br>• rendered video (information), MP4, WebM, MOV, GIF, PNG sequence or HLS directory, to renders/&lt;project-name>_&lt;YYYY-MM-DD>_&lt;HH-MM-SS>.&lt;ext> or the -o path<br>• batch render manifest with each row's variables, status, output, error and timing (information), manifest.json, to the common output directory<br>• timeline edits, with a receipt that reverts them (information), changed composition HTML and a receipt JSON, to the project files<br>• a Studio preview link for review (information), local URL, to handed to the person, http://localhost:&lt;port>/#project/&lt;project-name><br>• cloud renders and deployed render stacks on HeyGen, AWS or Google Cloud (action), remote render jobs, CloudFormation or Terraform stacks, to HeyGen's cloud, the user's AWS account or GCP project<br>• shared or published project (action), hosted URL, to HeyGen hosting<br>• feedback reports and usage telemetry (action), sent report, to the HyperFrames maintainers, through a public channel for feedback |
| **Sample output** | `beginframe capture · software gpu · compile 0.7s · setup 1.1s · capture 8.1s · encode 5.8s` |
| **Inputs** | • a HyperFrames project directory, a positional path, the current directory when omitted, optional for every command that works on a project, example `npx hyperframes render ./my-video --output ./out.mp4`<br>• a directory name for a new project, a positional argument, conditional for init, example `npx hyperframes init my-video --skip-skills`<br>• a website URL, a positional URL, conditional for capture, example `npx hyperframes capture https://example.com --json`<br>• an audio or video file, a path in a flag or a positional argument, optional for init with media, beats on a single file, example `npx hyperframes init my-video --skip-skills --audio track.mp3`<br>• composition variable values, a JSON object or a JSON file, optional for parametrized renders, example `npx hyperframes cloud render --variables '{"title":"Q4 Recap","theme":"dark"}'`<br>• a batch of variable rows, a JSON array, an object with rows, or a JSONL file with outputKey per line, conditional for batch renders, example `{ "outputKey": "renders/alice.mp4", "variables": { "name": "Alice" } }`<br>• a plan of several timeline edits, a JSON file, conditional for timeline apply, example `[{"verb": "move", "ref": "#outro", "time": "9"}]`<br>• output dimensions, --width and --height flags, conditional for lambda render and cloudrun render, example `npx hyperframes lambda render ./my-project --width 1920 --height 1080 --wait`<br>• the element the person selected in Studio, Studio selection read from a running preview, conditional for edits to this element or the current selection, example `npx hyperframes preview --context --json --context-fields selection` |
| **When an input is missing** | • no element is selected in Studio: the command returns no-selection, the person is asked to click the target element and the command is rerun<br>• no preview server is running for a selection query: the command returns preview-not-running, Studio is started with npx hyperframes preview --background<br>• a batch render without --output: the generated filename includes {index} so rows remain unique<br>• a placeholder in the batch output template is missing: the render reports an error<br>• a configured FFmpeg or FFprobe path points at a missing file: doctor reports it as missing<br>• the user is not signed in: auth status exits 1 as the normal offline state, and publish returns an authentication-required claim URL |
| **Exclusions** | • cloudrun only when the user explicitly wants self-managed Google Cloud infrastructure<br>• lambda only when the user wants self-managed AWS or distributed rendering, not for one-off short renders<br>• beats is a CLI utility, not a complete video workflow<br>• compare is a visual review surface, not a quality gate<br>• voice selection, Whisper model rules and the TTS to captions chain belong to the media-use skill<br>• share --public only when the user explicitly wants anyone with the link to access the review |
